Complete desktop rewrite for Windows and macOS.

- Usage, costs and sessions across 19 local coding tools.
- Hourly charts for Today and searchable filters.
- Account quotas, reset times and reset credits.
- Custom model prices, cache savings and speed premiums.
- Tool calls, MCP, skills and CSV exports.
- Fifteen themes with light, dark and system appearance.

Choose the arm64 DMG for Apple silicon or x64 for Intel Macs. Windows uses the x64 setup executable.

Installers are built by GitHub Actions and are unsigned. macOS builds are not notarized.
